📈 risk_scores ⭐ 新增 四分量加權風險分數計算結果 ▶
欄位型態說明
idBIGSERIAL自動編號主鍵
computed_atTIMESTAMPTZ計算時間
lat / lonFLOAT查詢座標
weather_riskFLOAT天氣風險子分數 0~1（Open-Meteo）
geopolitics_riskFLOAT地緣風險子分數 0~1（OFAC + MND ADIZ）
congestion_riskFLOAT壅塞風險子分數 0~1（IMF PortWatch）
vessel_riskFLOAT船舶風險子分數 0~1（外部輸入）
total_risk_scoreFLOAT加權總分 0~1（預設 w1=0.30 w2=0.40 w3=0.20 w4=0.10）
risk_levelVARCHARminimal｜low｜medium｜high｜critical
dominant_factorVARCHAR主因：weather｜geopolitics｜congestion｜vessel
adiz_sortie_countINT計算當下的共機架次（台灣海峽專用）
📥 資料來源本表所有欄位均為系統計算產出，無直接原始 API 對應；各子分數的輸入來源見下方說明
🔢 運算欄位 weather_risk ← marine_weather_obs（wind_speed、wave_height、visibility）正規化後加權； geopolitics_risk ← adiz_events.aircraft_count + OFAC 制裁名單 + JWC 保險區 + navigational_warnings.severity； congestion_risk ← chokepoint_daily.congestion_index 正規化； vessel_risk ← vessels（型別、噸位、吃水）+ ais_positions_summary.avg_sog； total_risk_score = w1×weather_risk + w2×geopolitics_risk + w3×congestion_risk + w4×vessel_risk； risk_level = total_risk_score 的分段標記（minimal/low/medium/high/critical）； dominant_factor = 四子分數中最高者
⚠️ 重複欄位adiz_sortie_count 是 adiz_events.aircraft_count 計算當下的快照複製（非外鍵關聯）；lat / lon 為查詢座標，與 stations.lat/lon、chokepoints.lat/lon 概念相同但非外鍵

🌬️ 氣象資料流 (R1)

Open-Meteo（免費） → marine_weather_obs → GET /risk/weather
CWA 氣象站（需 token） → marine_weather_obs → GET /risk/weather/archive
Open-Meteo 預報 → weather_forecast_series ⭐ → GET /risk/weather
CWA / JTWC 颱風 → typhoons → GET /risk/weather

🌊 海象資料流 (R2)

IOTH 台灣 5 港 → marine_weather_obs → GET /risk/ocean
NOAA NDBC 浮標 → marine_weather_obs → GET /risk/ocean
USCG 美西港口爬蟲 → uscg_port_status ⭐ → GET /risk/ocean

⚓ 瓶頸點資料流 (R3)

IMF PortWatch（每週二更新） → chokepoint_daily → GET /risk/chokepoint

🚨 地緣風險資料流 (R4)

國防部新聞稿爬蟲 → adiz_events ⭐ → GET /risk/geo
JCG / NGA / MARAD / UKMTO → navigational_warnings → GET /risk/geo

📈 風險分數計算流 (Feature)

marine_weather_obs + adiz_events + chokepoint_daily + vessels 🚢 → 計算 → risk_scores ⭐ → GET /feature/risk_score

🚢 船舶資料流 (shipping.db 整合)

shipping.db · vessels → 匯入 → vessels → vessel_risk 計算
shipping.db · positions（641 萬筆） → 每日彙整 → ais_positions_summary → 壅塞輔助指標
shipping.db · tpnet_in / tpnet_out → 合併匯入 → vessel_port_calls → 港口進出港分析

🔍 欄位來源對照總表
