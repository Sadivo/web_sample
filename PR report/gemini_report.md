> #### (三)、交通部航港局 iMarine 數據庫之深度整合與互補應用
> 
> 本專案為建構符合臺灣航商營運實務之決策支援系統，除了串接國際開源環境 API 之外，亦深度引進並整合交通部航港局 **iMarine (航港發展資料庫平臺)** 之權威海事數據，用以強化特徵工程（Feature Store）的基準值校正與模型訓練精準度。具體整合應用項目如下：
> 
> 1. **全球燃油價格 (WBP) 特徵校正**：系統的「經濟結算層（Layer 4）」在計算不同避險路徑的燃油成本增量時，動態讀取 iMarine 的「全球航運指數 — 世界燃油價格 (WBP)」作為高雄港與亞洲主要加油港的低硫燃油 (VLSFO) 與輕柴油 (MGO) 之基準盤價，確保油耗估算與實際市場盤價高度一致。
> 2. **國際商港貨櫃裝卸量與運能特徵**：為量化臺灣四大國際商港（高雄、基隆、台中、台北）的戰略重要性，系統調用 iMarine「快捷查詢/港口 — 國際商港貨櫃裝卸量」之歷史面板數據，將其作為「地緣政治風險指數」在臺灣海峽受擾動時之「供應鏈暴露價值（Value at Risk）」權重參數，精確計算出臺灣半導體與電子出口在航線中斷時的潛在經濟減損。
> 3. **泊靠時間與壅塞特徵校正**：利用 iMarine「簡易查詢/船舶 — 24小時泊靠時間分析」之大數據統計，獲取臺灣各港口不同船型的常態性泊靠等待時間基準。此基準用以與即時監測到的港口等待時間進行比對，從而精準派生出「港口實質壅塞指數」，支援 AI Agent 做出是否「跳港」或「調整靠港順序」之決策。
> 4. **進出臺灣船舶與 AIS 數據互補**：本專案將林子玲小組整理之 `shipping.db` 船舶動態資料，與 iMarine「快捷查詢/船舶 — 進出臺灣各國際商港船舶」之大數據庫進行主鍵（MMSI / IMO Number）關聯，補齊了 25,617 筆船舶之基本靜態特徵（如載重噸 DWT、船型、主機馬力、燃油類型），為動態降速最佳化模型提供了不可或缺的物理約束參數。
