## 三、修訂過程中排除的技術雷點（供開發參考）

在對 `.docx` XML 結構進行修改時，遇到並修復了以下 4 個 OOXML 結構問題：

1. **`w14:paraId` 數值越界**：新插入段落的 `paraId` 初始值（如 `IMAR0001`、`LAYER5001`）不合法（含非十六進位字元），後續版本改為合法 hex 值後仍超過上限 `0x80000000`，最終使用 `10000001`~`40000007` 範圍內的值。

2. **摘要段落插入位置錯誤**：首次插入摘要時，定位到目錄中的「摘要」TOC 項目（自訂樣式段落），而非正文摘要位置。修復方式：改為定位到 `<w:br w:type="page"/>` 分頁符後、「壹、研究主軸與目的」之前的位置。

3. **多餘的結束標籤殘留**：移除摘要舊位置的孤立段落時，留下了一個裸露的 `</w:p>` 結束標籤，導致 XML 解析失敗。以正則表達式修正。

4. **iMarine 段落被插入 `<w:r>` 內部**：插入 iMarine 段落時，`content[:idx]` 切割點落在一個 `<w:r><w:rPr>...</w:rPr>` 內部（`<w:t>` 之前），導致段落 `<w:p>` 被巢狀進 `<w:r>` 中，違反 OOXML 規範。修復方式：識別整個受損段落，重新提取 iMarine 段落並以正確的頂層位置重新插入。
