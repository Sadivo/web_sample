全球氣候變遷與地緣政治動盪，使現代航運面臨前所未有的營運挑戰。歐盟 ETS 碳費實施、IMO 2050 淨零排放路徑以及紅海危機等突發事件，將綠色合規與航線安全直接轉化為航商的剛性營運成本。然而，現有航港資訊多面臨資料分散、多源孤立且決策嚴重滯後之困境。 本專題開發「Ocean AI — 智慧綠色航運風險評估平台」，旨在打破海事資訊孤島。系統深度引進交通部航港局 iMarine (航港發展資料庫平臺) 之權威數據，並 live 整合全球氣象、即時海象、戰略瓶頸點與地緣政治等 15 個以上之異質資料源，建構強大的風險特徵庫（Feature Store）。目前，系統已成功開發並實測驗證 12 個多維度風險 API 端點（開發底層引擎代號為 GreenRoute 核心引擎），實現了「四分量加權風險評估模型」。本系統提供「智慧航線風險評估」與「綠色合規儀表板」等應用，協助航商將傳統被動的「經驗調度」升級為數據驅動的「自適應主動避險」，在兼顧 ESG 合規與航行安全的前提下，大幅提升臺灣航運的國際競爭力與韌性。
2. 【第四章】iMarine 數據整合專屬段落 (建議植入「採用數據說明」之後)
#### (三)、交通部航港局 iMarine 數據庫之深度整合與互補應用 本系統（Ocean AI）為建構符合臺灣航商營運與政策實務之決策支援系統，除了即時串接國際環境 API 外，亦深度整合交通部航港局 iMarine (航港發展資料庫平臺) 之權威海事數據。透過 iMarine 數據的基準校正，系統得以精確完成特徵工程（Feature Store）的歷史對齊與模型參數校正。具體整合應用項目如下： 1. **全球燃油價格 (WBP) 特徵校正**：系統的「經濟結算層」在計算不同繞航避險路徑的燃油成本增量時，動態讀取 iMarine 的「全球航運指數 — 世界燃油價格 (WBP)」作為高雄港與亞洲主要加油港的低硫燃油 (VLSFO) 與輕柴油 (MGO) 之基準盤價，確保路線碳費與油耗成本估算與實際市場盤價高度一致。 2. **國際商港貨櫃裝卸量與運能特徵**：為量化臺灣四大國際商港（高雄、基隆、台中、台北）的戰略暴露價值，系統調用 iMarine「快捷查詢/港口 — 國際商港貨櫃裝卸量」之歷史面板數據，將其作為「地緣政治風險指數」在臺灣海峽受擾動時之「供應鏈暴露價值（Value at Risk）」權重參數，精確計算出臺灣半導體與電子出口在航線中斷時的潛在經濟減損。 3. **泊靠時間與壅塞特徵校正**：利用 iMarine「簡易查詢/船舶 — 24小時泊靠時間分析」之大數據統計，獲取臺灣各港口不同船型的常態性泊靠等待時間基準。此基準用以與系統即時監測到的港口等待時間進行比對，從而精準派生出「港口實質壅塞指數」，支援決策模型做出是否「跳港」或「調整靠港順序」之自適應決策。 4. **進出臺灣船舶與 AIS 數據互補**：本系統將內部 shipping.db 船舶動態資料，與 iMarine「快捷查詢/船舶 — 進出臺灣各國際商港船舶」之數據進行主鍵（MMSI / IMO Number）關聯，補齊了 25,617 筆船舶之基本靜態特徵（如載重噸 DWT、船型、主機馬力、燃油類型），為自適應降速與避險最佳化模型提供了不可或缺 of 物理約束參數。
